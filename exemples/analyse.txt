<page suivante h1>Systèmes dynamiques : intégration numérique
Un système d'équations différentielles autonome se lit dans son espace des phases. docdg l'intègre par une méthode de Runge-Kutta adaptative et en trace les trajectoires : cycle limite, orbites fermées, attracteur étrange.

<h2>L'oscillateur de Van der Pol : un cycle limite
L'amortissement change de signe avec l'amplitude : négatif près de l'équilibre, il amplifie les petites oscillations ; positif au-delà, il freine les grandes.
<Résoudre>numériquement l'équation différentielle x'' - μ(1 - x^2)x' + x = 0, avec μ = 2, x(0) = 0,1 et x'(0) = 0, sur [0 ; 30], le portrait de phase
	<remarque>Quelle que soit la condition initiale, la trajectoire rejoint le même cycle fermé : c'est un cycle limite, qu'aucune équation linéaire ne peut produire.

<h2>Proies et prédateurs : Lotka-Volterra
<Résoudre>numériquement le système différentiel, avec a = 1,1, b = 0,4, c = 0,4, d = 0,1, x(0) = 10 et y(0) = 10, sur [0 ; 50] {
	x' = x(a - b y)
	y' = y(d x - c)
}
	<remarque>Les deux populations oscillent en décalage : les prédateurs culminent après les proies.

<h2>Le système de Lorenz et le chaos
<Résoudre>numériquement le système différentiel, avec σ = 10, ρ = 28, β = 8/3, x(0) = 1, y(0) = 1 et z(0) = 1, sur [0 ; 40], en traçant z en fonction de x, rtol = 1e-8, atol = 1e-10 {
	x' = σ(y - x)
	y' = x(ρ - z) - y
	z' = xy - β z
}
	<remarque>Les tolérances sont resserrées : sur un système chaotique, deux calculs qui diffèrent d'un arrondi finissent par diverger, et seule la forme de l'attracteur est une donnée robuste.

<h2>Un problème aux limites non linéaire : la chaînette
Une chaîne suspendue par ses deux extrémités, à la même hauteur, prend une forme qui vérifie y'' = √(1 + y'²). Les conditions portent sur les deux points d'attache.
<Résoudre>numériquement l'équation différentielle y'' = sqrt(1 + y'^2), d'inconnue y(x), avec y(-1) = 1 et y(1) = 1, sur [-1 ; 1]
	<remarque>La solution est un cosinus hyperbolique : y(x) = ch(x) − ch(1) + 1, de pente sh(1) ≈ 1,175 aux points d'attache.

<h1algo>Ce que ce document couvre

Déclarer une variable et l'initialiser, poser une question au lecteur, décider selon une condition, répéter un traitement. Chaque structure s'y montre d'abord seule, puis les deux se mêlent : une condition à l'intérieur d'une boucle décide, tour par tour, ce qui reste dans le document.

<h1algo>Variables et sortie

Une variable se pose avec `soit`, se relit avec `#`, entre dans un calcul avec `#{...}` — l'équivalent d'une affectation suivie d'un affichage.

soit tva: un décimal = 0,2
soit prix: un entier = 150
Le prix TTC est #{prix * (1 + tva)} euros.

<h1algo>Une valeur initialisée

Pour conserver la navigation libre entre les chapitres, cet exemple utilise un entier déjà initialisé.

Pour découvrir la saisie interactive bloquante, consulter exclusivement l’atelier placé à la fin de basique.txt.

soit âge: un entier = 16
soit majorité: une chaîne de caractères = si âge moins de 18 { mineur(e) } sinon { majeur(e) }
Tu es #majorité.


<h1algo>Une boucle simple

`pour` répète un bloc un nombre de fois connu à l'avance — l'équivalent d'un `for`.

pour k: un entier naturel de 1 à 3 {
	Ligne #k : le carré de #k vaut #{k*k}.
}

<h1algo>Une répétition sans compteur

`répéter ... fois` répète un bloc quand le rang n'a pas à paraître — la répétition du Logo, sans variable à nommer.

répéter 3 fois {
	Une ligne de plus, à l'identique.
}

<h1algo>Une condition simple

`si ... sinon` choisit entre deux issues, une fois, sans répétition.

soit note: un entier = 12
si note au moins 10 {
	Admis avec #note.
}
sinon {
	Ajourné.
}

<h1algo>Une boucle avec un pas négatif

Le pas se règle en prose, comme tout réglage : `avec un pas de p`. Ici la boucle avance de 0,25 en 0,25.

pour k: un décimal de 2 à 0 avec un pas de -0,25 {
	Terme #{défaut(-4*k)+9} : #k.
}

<h1algo>Une boucle qui filtre

<h2algo>Les multiples de 3 entre 1 et 20

Aucune ligne n'est écrite pour les tours silencieux — ils n'existent simplement pas dans le résultat. Chaque tour retenu forme sa propre ligne : c'est la boucle elle-même qui écrit le document, tour après tour.

<Dresser>un tableau {
	<mc>	<mc>
	n	Multiple de 3 ?
	pour n: un entier naturel de 1 à 20 {
		si n % 3 vaut 0 {
			[#n]	[oui]
		}
	}
}

<page suivante h1algo>Chercher les diviseurs d'un entier

Un entier \(d\) divise \(n\) lorsque le reste de la division de \(n\) par \(d\) est nul. Balayer tous les diviseurs candidats de 1 à \(n\), et ne retenir que ceux qui divisent effectivement, donne la liste complète des diviseurs — la première brique, sur le papier comme ici, de tout test de primalité.

<Dresser>un tableau sécable {
	<mc>	<mc>
	Diviseur	de 84
	pour d: un entier naturel de 1 à 84 {
		si 84 % d vaut 0 {
			[#d]	[convient]
		}
	}
}

Un nombre premier n'a, par définition, aucun diviseur strictement compris entre 1 et lui-même. La table ci-dessus liste ceux de 84 — huit en tout, largement plus que les deux attendus d'un nombre premier.

<h1algo>Filtrer par intervalle

`appartient à` et sa négation `n'appartient pas à` filtrent un intervalle aussi simplement qu'un test de divisibilité — utile chaque fois que l'algorithme cherche « à partir de quel rang » une grandeur franchit un seuil.

<Dresser>un tableau {
	<mc>	<mc>	<mc>
	Rang	Terme	Écart
	pour n: un entier naturel de 0 à 20 {
		si (n appartient à [16;20]) {
			[#n]	[#{2^(n+1) - 1}]	[#{2^n}]
		}
	}
}


<h1algo>L'opérateur ternaire

`si ... sinon` peut aussi produire une valeur plutôt que du texte — affecté directement à une variable, comme un opérateur ternaire.

soit n: un entier = 17
soit parité: une chaîne de caractères = si n % 2 vaut 0 { pair } sinon { impair }
#n est #parité.

<h1algo>Conditions composées

`et` comme `ou` combinent deux conditions dans le même test ; les parenthèses en précisent l'ordre quand les deux se mêlent.

<Dresser>un tableau {
	<mc>	<mc>
	n	Retenu
	pour n: un entier naturel de 1 à 30 {
		si n % 3 vaut 0 et n % 5 vaut 0 {
			[#n]	[multiple de 15]
		}
	}
}

soit n: un entier naturel = 5
si (n % 3 vaut 0 et n % 5 vaut 0) ou n vaut 5 {
	Retenu par l'exception.
}
sinon {
	Écarté.
}

<h1algo>L'accumulateur

Une variable posée avant la boucle et réaffectée à l'intérieur garde sa valeur d'un tour au suivant : c'est l'accumulateur, celui qui totalise une somme ou compte les cas retenus.

soit somme: un entier naturel = 0
pour k: un entier naturel de 1 à 100 {
	somme = somme + k
}
La somme des entiers de 1 à 100 vaut #somme.

soit produit: un entier naturel = 1
pour k: un entier naturel de 1 à 5 {
	produit = produit * k
}
La factorielle de 5 vaut #produit.

<h1algo>Compter sous condition

L'accumulateur placé à l'intérieur d'un `si` ne s'incrémente que sur les tours retenus — le compteur de l'algorithmique classique.

soit diviseurs: un entier naturel = 0
pour d: un entier naturel de 1 à 84 {
	si 84 % d vaut 0 {
		diviseurs = diviseurs + 1
	}
}
84 possède #diviseurs diviseurs.

soit diviseurs: un entier naturel = 0
pour d: un entier naturel de 1 à 83 {
	si 83 % d vaut 0 {
		diviseurs = diviseurs + 1
	}
}
83 en possède #diviseurs : c'est donc un nombre premier.

<page suivante h1algo>Les boucles conditionnelles

`pour` répète un nombre de fois connu d'avance. Quand ce nombre dépend du calcul lui-même, c'est `tant que` qui convient : la condition est vérifiée <gras>{avant} chaque passage, si bien que la boucle peut n'en faire aucun.

soit p: un entier naturel = 1
soit rang: un entier naturel = 0
tant que p < 1000 faire {
	p = p * 2
	rang = rang + 1
}
La première puissance de 2 supérieure à 1000 est #p, atteinte au rang #rang.

La variante `faire … tant que` vérifie la condition <gras>{après} chaque passage : le corps s'exécute donc au moins une fois, même lorsque la condition est fausse dès le départ.

soit n: un entier naturel = 10
faire {
	Passage unique, avec n valant #n.
	n = n + 1
} tant que n < 3

Les deux formes reposent sur l'accumulateur de la section précédente : sans une variable qui avance d'un tour à l'autre, une boucle conditionnelle ne s'arrêterait jamais.

<h1algo>Interrompre une répétition

Deux mots gouvernent le cours d'une boucle. `sortir` l'arrête entièrement — c'est la recherche qui cesse dès qu'elle a trouvé. `continuer` n'arrête que le tour en cours.

soit premier_diviseur: un entier naturel = 0
pour d: un entier naturel de 2 à 100 {
	si reste de 91 par d vaut 0 {
		premier_diviseur = d
		sortir
	}
}

Le plus petit diviseur de 91 autre que 1 est #premier_diviseur.

pour k: un entier naturel de 1 à 6 {
	si reste de k par 2 vaut 0 {
		continuer
	}
	[#k]
}

Seuls les rangs impairs ont laissé une trace.

<h1algo>Trois conteneurs, une seule grammaire

Un conteneur se déclare comme toute variable — le nom, le deux-points, le type en toutes lettres, puis la valeur. Le type est toujours écrit ; le point-virgule sépare les éléments ; l'accolade les rassemble. Les indices commencent à 0, comme en NSI.

<h1algo>La liste

soit notes: une liste de décimaux = {12,5 ; 15 ; 9,5}
soit mots: une liste de chaînes de caractères = {"chat" ; "chien" ; "cheval"}

Le dièse affiche le conteneur entier : #notes — et l'indice lit un élément : la deuxième note est #notes[1], le premier mot est #mots[0]. Un élément entre dans un calcul comme toute valeur : le double de la deuxième note vaut #{notes[1] * 2}.

L'écriture indexée modifie une case existante, sans soit puisque rien n'est déclaré :

notes[2] = 14

Après correction : #notes. L'indice 7 dépasserait les trois éléments disponibles : docdg refuserait cette lecture. Le cas fautif reste testé séparément.

<h2algo>Grandir par concaténation

Une liste déclarée vide grandit par +, qui concatène toujours deux conteneurs — l'élément ajouté s'écrit donc en singleton, entre accolades. La réaffectation ne redit ni soit ni le type : ils ont été posés à la déclaration.

soit S: une liste d'entiers = {}
pour k: un entier naturel de 1 à 5 {
	S = S + {k * k}
}

Les cinq premiers carrés : #S.

<h1algo>Le dictionnaire

soit trajets: un dictionnaire de chaînes de caractères et d'entiers = {"Marche": 5 ; "Bus": 3}

La clé lit sa valeur : à pied, #trajets["Marche"] minutes. Le + ajoute une paire :

trajets = trajets + {"Vélo": 7}

Le dictionnaire complet : #trajets. Chercher une clé absente comme Métro serait refusé : la démonstration utilise seulement les clés existantes.

La boucle dans livre les clés, et l'indexation retrouve chaque valeur :

pour t: une chaîne de caractères dans trajets {
	#t : #{trajets[t]} minutes.
}

<page suivante h1algo>La matrice

Une matrice porte ses dimensions dans son type. La forme littérale tient sur une ligne ; la forme bloc s'aligne à l'œil dans l'éditeur — tabulations entre colonnes, retours à la ligne entre rangées, aucun point-virgule :

soit A: une matrice 2×2 d'entiers = {{1 ; 2} ; {3 ; 4}}
soit B: une matrice 2×2 d'entiers = {
	5	6
	7	8
}

A vaut #A et B vaut #B. Une case se lit par [ligne ; colonne] : #A[0 ; 1] puis #B[1 ; 0].

Déclarée avec {}, une matrice naît remplie de ses valeurs par défaut, puis se remplit case par case :

soit T: une matrice 3×3 d'entiers = {}
pour i: un entier naturel de 0 à 2 {
	pour j: un entier naturel de 0 à 2 {
		T[i ; j] = (i + 1) * (j + 1)
	}
}

La table de multiplication : #T — et sa case centrale : #T[1 ; 1].

<h1algo>Composer les conteneurs

Un tableau à plusieurs dimensions dont la taille n'est pas connue d'avance est une liste de listes. La rangée se déclare dans la boucle — elle repart vide à chaque tour — pendant que le conteneur extérieur, déclaré avant, accumule :

soit M: une liste de listes d'entiers = {}
pour i: un entier naturel de 0 à 2 {
	soit rangée: une liste d'entiers = {}
	pour j: un entier naturel de 0 à 3 {
		rangée = rangée + {i * j}
	}
	M = M + {rangée}
}

Le résultat : #M.

<h1algo>Les quatre types de nombres

Le langage distingue les ensembles tels que les mathématiques les enseignent, et il respecte leur emboîtement $NN inclus dans ZZ inclus dans DD inclus dans QQ inclus dans RR inclus dans CC$ : un entier relatif appartient à $ZZ$, un décimal à $DD$ — son écriture décimale est finie — un rationnel à $QQ$, un réel à $RR$, et un complexe à $CC$, sous sa forme algébrique $a + ib$.

soit ent: une liste d'entiers = {1 ; -4 ; 12}
soit dec: une liste de décimaux = {12,5 ; 0,25 ; 15}
soit ree: une liste de réels = {1/3 ; racine(2) ; 2,5}
soit cpx: une liste de complexes = {1 + 2i ; -i}

Entiers : #ent — décimaux : #dec — réels : #ree — complexes : #cpx. Le second complexe vaut #cpx[1], dont la partie réelle est nulle.

L'inclusion $DD inclus dans QQ$ ne se remonte pas : un tiers est un rationnel parfaitement légitime, mais son écriture décimale est illimitée, donc il n'appartient pas à $DD$ — et docdg le dit, en nommant les deux ensembles et la sortie :

Une liste de décimaux ne peut pas contenir un tiers : le cas fautif, volontaire, reste dans les tests historiques.

<h1algo>Le type protège

Le type déclaré est vérifié à la déclaration comme à la réaffectation. Une liste d'entiers contenant 2,5 serait refusée ; ce cas reste vérifié par les tests historiques.

<page suivante h1algo>Mesurer, chercher, ranger

Un conteneur ne se contente pas de se remplir : il se mesure, se parcourt, se range. Le vocabulaire suit une règle simple — un nom pour ce qui produit une valeur, un verbe pour ce qui répond par oui ou non.

soit notes: une liste d'entiers = {12 ; 15 ; 9 ; 18 ; 11}

<Dresser>un tableau {
	<mg>	<mc>
	Écriture	Résultat
	[longueur(notes)]	[#{longueur(notes)}]
	[somme(notes)]	[#{somme(notes)}]
	[min(notes)]	[#{min(notes)}]
	[max(notes)]	[#{max(notes)}]
	[trier(notes)]	[#{trier(notes)}]
	[inverser(notes)]	[#{inverser(notes)}]
	[notes contient(15)]	[#{notes contient(15)}]
	[dans notes indice de(15)]	[#{dans notes indice de(15)}]
	[dans notes insérer(0 ; 20)]	[#{dans notes insérer(0 ; 20)}]
	[dans notes supprimer(2)]	[#{dans notes supprimer(2)}]
	[dans notes ajouter(7)]	[#{dans notes ajouter(7)}]
	[notes]	[#notes]
}

Trois écritures pour une même opération, selon ce qui se lit le mieux : la forme fonctionnelle insérer(notes ; 0 ; 20), la forme prépositionnelle dans notes insérer(0 ; 20), et pour les questions par oui ou non la forme directe notes contient(15). C'est la phrase qui commande, non la machine.

<h2algo>La division euclidienne

Le quotient et le reste se disent comme au collège, avec leurs prépositions :

<Dresser>un tableau {
	<mg>	<mc>
	Écriture	Résultat
	[quotient de 17 par 5]	[#{quotient de 17 par 5}]
	[reste de 17 par 5]	[#{reste de 17 par 5}]
	[quotient de longueur(notes) par 2]	[#{quotient de longueur(notes) par 2}]
}

La forme brève quotient(17 ; 5) reste admise, mais la phrase dit lequel des deux nombres est le dividende.

Chacune de ces écritures rend une <gras>nouvelle liste : la série de départ n'est jamais modifiée. La primitive longueur mesure aussi bien un dictionnaire, une matrice ou une chaîne de caractères.

Le conteneur peut aussi précéder la primitive, ce qui se lit comme une phrase : notes contient(15) rend #{notes contient(15)}, et notes indice de(15) rend #{notes indice de(15)}. Les deux écritures sont admises.

<h2algo>La chaîne de caractères
Une chaîne se déclare comme un nombre — les guillemets délimitent la valeur sans lui appartenir.
soit devise: une chaîne de caractères = "liberté égalité fraternité"

#devise compte #{longueur(devise)} lettres, dont les huit premières sont #{devise[0 à 7]}. La première est #{devise[0]} — une lettre est une chaîne d'un seul caractère, docdg n'a pas de type distinct.

La chaîne se parcourt lettre à lettre. Les crochets ne servent qu'à rendre chaque tour visible : sans eux, sept lettres sur sept lignes consécutives ne feraient qu'un seul paragraphe, et se reliraient comme le mot de départ.

pour c: une chaîne de caractères dans "exact" {
	[#c]
}

<h2algo>Écrire une suite sur une ligne
Une boucle qui affiche met chaque tour sur sa ligne. Pour aligner une suite sur une seule ligne, avec le séparateur qu'on veut, on la compacte pour enlever les espaces, puis on la joint :

#{joindre(compacter("un code") ; ", ")}

soit v: une liste d'entiers = {12 ; 15 ; 9}

#{joindre(v ; ", ")} — et avec un autre séparateur : #{joindre(v ; " — ")}.

Le chemin inverse découpe une ligne en ses morceaux : #{découper("un code" ; " ")}. Avec un séparateur vide, ce sont les lettres : #{découper("code" ; "")}.

Une chaîne écrite sur place se met entre guillemets. Sans eux, docdg refuse plutôt que de faire un tour unique sur la phrase entière.

<Dresser>un tableau {
	<mg>	<mc>
	Écriture	Résultat
	[majuscule("été")]	[#{majuscule("été")}]
	[minuscule("BONJOUR")]	[#{minuscule("BONJOUR")}]
	[sans accents("élève")]	[#{sans accents("élève")}]
	[élaguer("  bonjour  ")]	[[#{élaguer("  bonjour  ")}]]
	[compacter("un code")]	[#{compacter("un code")}]
	[inverser(devise)]	[#{inverser("liberté")}]
	[devise contient("égalité")]	[#{devise contient("égalité")}]
	[code("B")]	[#{code("B")}]
	[caractère(97)]	[#{caractère(97)}]
	[texte(42)]	[#{texte(42)}]
	[nombre("1,5")]	[#{nombre("1,5")}]
}

majuscule accentue les capitales — ÉTÉ et non ETE, comme l'exige la typographie française. code et caractère font le va-et-vient entre une lettre et son rang Unicode : c'est ce qui permet d'écrire un chiffrement.

Chercher un élément absent déclencherait une erreur explicite. Sur la liste existante, la position de 12 vaut #{indice de(12 ; notes)}.

<h2algo>La tranche

Deux positions séparées par à désignent une portion, bornes incluses — comme pour n: un entier naturel de 1 à 5 fait cinq tours.

Les trois premières notes : #{notes[0 à 2]}. La dernière seule : #{notes[4 à 4]}.

Une tranche dont la borne de gauche dépasse celle de droite est simplement vide : #{notes[3 à 2]}. Ce n'est pas une faute, et c'est ce qui permet de conclure une fusion de deux listes triées en une seule ligne.

<h2algo>Le classement des chaînes

soit mots: une liste de chaînes de caractères = {"Zoé" ; "école" ; "avion" ; "èdre"}

#{trier(mots)}

L'accent ne retourne pas le mot à la fin de l'alphabet : la comparaison porte d'abord sur les lettres dépouillées, l'accent ne servant qu'à départager — comme dans un dictionnaire.

<h1algo>Deux sortes de fonctions

docdg distingue la fonction mathématique — objet d'étude qu'on dérive, qu'on trace, dont on cherche les limites — et la fonction algorithmique, calcul nommé qu'on réutilise. Les chevrons marquent la première, le soit nu la seconde, exactement comme ils distinguent déjà la matrice de l'algèbre du conteneur de l'algorithmique.

Une fonction algorithmique déclare le type de chacun de ses paramètres et celui de sa valeur, avec l'article, comme partout ailleurs dans le langage : un entier, une liste de réels. Elle s'appelle ensuite par son nom, arguments séparés par le point-virgule comme toute donnée.

<h1algo>La forme la plus simple

soit addition(a: un entier ; b: un entier): un entier = a + b

L'appel se fait dans un calcul : #{addition(3 ; 7)}, ou #{addition(12 ; 30)}.

Les types ne sont pas décoratifs : un décimal à la place d'un entier, ou un argument manquant, seraient refusés. Avec deux entiers, le calcul est valide : #{addition(2 ; 7)}.

<h1algo>Un corps entre accolades

Quand le calcul tient en une expression, l'accolade est facultative :

soit aire(L: un réel ; l: un réel): un réel = { L * l }

L'aire d'un rectangle de 2,5 sur 4 vaut #{aire(2,5 ; 4)}.

<h2algo>Plusieurs instructions

Dès que le corps compte plusieurs lignes, la valeur produite doit être désignée par retourne — rien n'est implicite :

soit hypoténuse(a: un réel ; b: un réel): un réel = {
	soit carrés: un réel = a*a + b*b
	retourne racine(carrés)
}

Le triangle de côtés 3 et 4 a pour hypoténuse #{hypoténuse(3 ; 4)}, celui de côtés 5 et 12 a pour hypoténuse #{hypoténuse(5 ; 12)}.

Une fonction dont le corps ne retourne rien serait refusée. Voici la forme correcte avec un retour explicite :

soit identité(a: un entier): un entier = {
	retourne a
}

Appel : #{identité(3)}.

<h1algo>Fonctions et boucles

Une fonction s'appelle partout où un calcul est admis — dans le texte, dans une rangée de tableau, dans la condition d'une boucle, dans un accumulateur.
soit carré(n: un entier): un entier = n * n
soit somme: une liste d'entiers = {}
pour k: un entier naturel de 1 à 6 {
	somme = somme + {carré(k)}
}

Les six premiers carrés, calculés par la fonction et rassemblés dans une liste : #somme.
Et le test de divisibilité, écrit une fois, réutilisé partout :

soit divise(d: un entier ; n: un entier): un entier = n % d

<Dresser>un tableau {
	<mc>	<mc>
	Diviseur	de 60
	pour d: un entier naturel de 1 à 60 {
		si divise(d ; 60) vaut 0 {
			[#d]	[convient]
		}
	}
}

<h1algo>Recevoir et rendre un conteneur
Un paramètre peut être une collection, un dictionnaire, une matrice ou un texte : son type s'écrit comme celui d'une variable.
soit moyenne(v: une liste de réels): un réel = {
	soit s: un réel = 0
	pour x: un réel dans v {
		s = s + x
	}
	retourne s / longueur(v)
}
soit notes: une liste de réels = {12,5 ; 15 ; 9,5 ; 18 ; 11}
La moyenne de la série vaut #{moyenne(notes)}.
La primitive longueur mesure un conteneur — collection, dictionnaire, matrice ou texte.
Une collection d'entiers est acceptée là où une liste de réels est attendue : la fonction reçoit une copie, elle ne peut donc rien renvoyer dans la série de l'appelant.
<h2algo>Rendre une collection
soit doublée(v: une liste d'entiers): une liste d'entiers = v + v
La série {1 ; 2 ; 3} doublée donne #{doublée({1 ; 2 ; 3})}.
<h2algo>Chercher dans une collection reçue
soit recherche(v: une liste d'entiers ; x: un entier): un entier = {
	soit trouvé: un entier = -1
	pour i: un entier naturel de 0 à longueur(v) - 1 {
		si v[i] vaut x {
			trouvé = i
		}
	}
	retourne trouvé
}
15 occupe la position #{recherche({4 ; 8 ; 15 ; 16} ; 15)} ; 7 n'y figure pas : #{recherche({4 ; 8 ; 15 ; 16} ; 7)}.
<h2algo>Modifier une copie locale
Un nom posé sur un conteneur reçu en désigne une copie : l'écriture indexée n'atteint jamais la série de l'appelant.
soit modifie(v: une liste d'entiers): une liste d'entiers = {
	soit t: une liste d'entiers = v
	t[0] = 100
	retourne t
}
soit série: une liste d'entiers = {1 ; 2 ; 3}
Copie modifiée : #{modifie(série)} — série d'origine : #série.

<h1algo>Les primitives dans un corps
Les primitives de conteneur — longueur, trier, inverser, somme, min, max, quotient, contient, indice de, insérer, supprimer, ajouter — s'emploient partout, y compris dans un corps de fonction :
soit médiane(v: une liste de réels): un réel = {
	soit t: une liste de réels = trier(v)
	retourne t[quotient de longueur(t) par 2]
}
La médiane de {7 ; 1 ; 5 ; 3 ; 9} vaut #{médiane({7 ; 1 ; 5 ; 3 ; 9})} — la série est d'abord triée, puis on lit la valeur du milieu. La formule vaut pour un nombre impair de valeurs.

Un nom de fonction tient en un seul mot : le nom composé est réservé aux mots du langage lui-même, comme indice de ou sans accents. Quand deux mots sont vraiment nécessaires — parce que l'algorithme porte ce nom, tel le tri par insertion — le trait bas les relie : tri_par_insertion. Partout ailleurs, un mot suffit et se lit mieux.

<h1algo>Les k plus proches voisins

<Tracer>la classe du point (3 ; 3) par les 3 plus proches voisins parmi {(1;1) A, (2;1) A, (1;2) A, (6;6) B, (7;6) B, (6;7) B, (4;2) A}

Le choix de k compte. Pour le point (4,5 ; 4,5), le plus proche voisin est de classe B :

<h1algo>La récursivité

Une fonction peut s'appeler elle-même. La condition d'arrêt s'écrit avec si … sinon, qui produit ici une valeur plutôt qu'un texte :

soit factorielle(n: un entier): un entier = si n vaut 0 { 1 } sinon { n * factorielle(n - 1) }

Les premières factorielles : #{factorielle(1)}, #{factorielle(2)}, #{factorielle(3)}, #{factorielle(4)}, #{factorielle(5)}, #{factorielle(6)}.

La suite de Fibonacci se définit de la même façon, avec deux appels par tour :

soit fib(n: un entier): un entier = si n moins de 2 { n } sinon { fib(n - 1) + fib(n - 2) }

Les douze premiers termes, dressés par une boucle qui appelle la fonction à chaque rang :
<Dresser>un tableau {
	<mc>	<md>
	Rang	Terme
	pour n: un entier naturel de 0 à 11 {
		[#n]	[#{fib(n)}]
	}
}

La récursion est bornée : au-delà de deux cents appels imbriqués, docdg s'arrête et le dit, plutôt que d'épuiser la pile.

<h1algo>Les algorithmes classiques

Les exercices du programme s'écrivent avec ce qui précède : une fonction, une boucle, une collection reçue en copie.

<h2algo>Chercher

soit recherche(v: une liste d'entiers ; x: un entier): un entier = {
	pour i: un entier naturel de 0 à longueur(v) - 1 {
		si v[i] vaut x {
			retourne i
		}
	}
	retourne -1
}

Le `retourne` placé dans la boucle en sort sur-le-champ : c'est le geste que montre tout manuel. Dans une série triée, la dichotomie coupe l'intervalle en deux à chaque tour.

soit dichotomie(v: une liste d'entiers ; x: un entier): un entier = {
	soit g: un entier naturel = 0
	soit d: un entier = longueur(v) - 1
	tant que g moins de d faire {
		soit m: un entier naturel = quotient de g + d par 2
		si v[m] moins de x {
			g = m + 1
		} sinon {
			d = m
		}
	}
	retourne g
}

soit premiers: une liste d'entiers = {2 ; 3 ; 5 ; 7 ; 11 ; 13 ; 17 ; 19}

11 occupe la position #{dichotomie(premiers ; 11)} ; recherche(premiers ; 4) ne le trouve pas : #{recherche(premiers ; 4)}.

<h2algo>Trier

soit tri_par_insertion(v: une liste d'entiers): une liste d'entiers = {
	soit t: une liste d'entiers = v
	pour i: un entier naturel de 1 à longueur(t) - 1 {
		soit x: un entier = t[i]
		soit j: un entier = i - 1
		tant que j au moins 0 et t[j] plus de x faire {
			t[j + 1] = t[j]
			j = j - 1
		}
		t[j + 1] = x
	}
	retourne t
}

soit tri_par_sélection(v: une liste d'entiers): une liste d'entiers = {
	soit t: une liste d'entiers = v
	pour i: un entier naturel de 0 à longueur(t) - 2 {
		soit p: un entier naturel = i
		pour j: un entier naturel de i + 1 à longueur(t) - 1 {
			si t[j] moins de t[p] {
				p = j
			}
		}
		soit x: un entier = t[i]
		t[i] = t[p]
		t[p] = x
	}
	retourne t
}

soit désordre: une liste d'entiers = {5 ; 2 ; 9 ; 1 ; 5 ; 6}

<Dresser>un tableau {
	<mg>	<mg>
	Méthode	Résultat
	[Insertion]	[#{tri_par_insertion(désordre)}]
	[Sélection]	[#{tri_par_sélection(désordre)}]
	[Série d'origine]	[#désordre]
}

La série de départ n'a pas bougé : une fonction rend une valeur, elle ne modifie rien à distance. La primitive trier(désordre) donne le même résultat — #{trier(désordre)} — mais on n'apprend pas à trier en l'appelant.

<h2algo>Fusionner deux listes triées

soit fusion(a: une liste d'entiers ; b: une liste d'entiers): une liste d'entiers = {
	soit r: une liste d'entiers = {}
	soit i: un entier naturel = 0
	soit j: un entier naturel = 0
	tant que i moins de longueur(a) et j moins de longueur(b) faire {
		si a[i] au plus b[j] {
			r = ajouter(r ; a[i])
			i = i + 1
		} sinon {
			r = ajouter(r ; b[j])
			j = j + 1
		}
	}
	retourne r + a[i à longueur(a) - 1] + b[j à longueur(b) - 1]
}

#{fusion({1 ; 4 ; 7 ; 9} ; {2 ; 3 ; 8})}

À la sortie de la boucle, l'une des deux tranches finales est toujours vide — une tranche dont la borne de gauche dépasse celle de droite n'est pas une faute. C'est ce qui permet de conclure en une ligne.

<h1algo>Les structures de données

<h2algo>Les écrire à la main

Sept lignes suffisent, et aucune n'est du moteur : la structure du programme de terminale se démontre au tableau au lieu d'être cachée dans le logiciel. On les nomme ici avec un suffixe, car une fonction qu'on écrit masque la primitive du même nom — c'est voulu, pour que l'élève puisse écrire la sienne, mais cela empêcherait d'employer les deux dans un même document.

soit empile_liste(p: une liste d'entiers ; x: un entier): une liste d'entiers = ajouter(p ; x)
soit sommet_liste(p: une liste d'entiers): un entier = p[longueur(p) - 1]
soit dépile_liste(p: une liste d'entiers): une liste d'entiers = p[0 à longueur(p) - 2]

soit enfile_liste(f: une liste d'entiers ; x: un entier): une liste d'entiers = ajouter(f ; x)
soit tête_liste(f: une liste d'entiers): un entier = f[0]
soit défile_liste(f: une liste d'entiers): une liste d'entiers = f[1 à longueur(f) - 1]

soit vide_liste(c: une liste d'entiers): un booléen = si longueur(c) vaut 0 { 1 } sinon { 0 }

soit p: une liste d'entiers = empile_liste(empile_liste(empile_liste({} ; 1) ; 2) ; 3)

La pile #p a pour sommet #{sommet_liste(p)} ; après dépilement il reste #{dépile_liste(p)}. La file {1 ; 2 ; 3} a pour tête #{tête_liste({1 ; 2 ; 3})} et laisse #{défile_liste({1 ; 2 ; 3})}.

Le type de p s'écrit comme partout ailleurs : une seule règle, sans exception pour les valeurs composées.

<h2algo>Celles du langage

Une fois l'exercice fait, le langage les fournit — avec leur discipline, qui est tout leur intérêt. Une file n'a pas de sommet, une pile n'a pas de tête, et aucune des deux ne s'indexe.

soit q: une pile d'entiers = {}
q = empiler(q ; 1)
q = empiler(q ; 2)

La pile #q a pour sommet #{sommet(q)} ; dépilée, il reste #{dépiler(q)}. Elle est vide ? #{est vide(q)}

soit r: une file d'entiers = {1 ; 2 ; 3}

La file #r a pour tête #{tête(r)} ; défilée, il reste #{défiler(r)}.

<page suivante h2algo>Rendre plusieurs valeurs : le p-uplet

Un p-uplet a une longueur fixe et des types qui peuvent différer, là où une collection est homogène et de longueur libre. Il s'écrit entre parenthèses, comme un point du plan.

soit divise(a: un entier ; b: un entier): (un entier ; un entier) = (quotient de a par b ; reste de a par b)

soit (q: un entier ; r: un entier) = divise(17 ; 5)

17 = 5 × #q + #r — la déliaison pose les deux noms d'un coup.

L'exercice qui justifie à lui seul le p-uplet : deux résultats, un seul parcours.

soit extrema(v: une liste d'entiers): (un entier ; un entier) = {
	soit petit: un entier = v[0]
	soit grand: un entier = v[0]
	pour x: un entier dans v {
		si x moins de petit { petit = x }
		si x plus de grand { grand = x }
	}
	retourne (petit ; grand)
}

soit (mini: un entier ; maxi: un entier) = extrema({12 ; 15 ; 9 ; 18})

La plus petite valeur est #mini, la plus grande #maxi.

Les membres se lisent aussi par leur rang, et les types peuvent différer :

soit c: (un entier ; une chaîne de caractères) = (3 ; "trois")

#c — dont le second membre est #{c[1]}.

<h1algo>Tirer au hasard

aléatoire(a ; b) rend un entier entre les deux bornes, comprises. Deux compilations donnent deux tirages : c'est ce qu'une simulation attend.

soit lancers(n: un entier): un entier = {
	soit six: un entier naturel = 0
	pour k: un entier naturel de 1 à n {
		si aléatoire(1 ; 6) vaut 6 {
			six = six + 1
		}
	}
	retourne six
}

Sur 60 lancers d'un dé, #{lancers(60)} six — pour une espérance de 10.

<h1algo>Les objets

Une classe rassemble des données et ce qu'on sait en faire. Elle se déclare comme une phrase de mathématiques, et le type de ses attributs porte son article comme partout ailleurs : une seule règle, du premier `soit` au dernier.

soit une classe Point {
	abscisse: un réel
	ordonnée: un réel

	soit norme(): un réel = racine(abscisse * abscisse + ordonnée * ordonnée)
	soit translaté(dx: un réel ; dy: un réel): Point = Point(abscisse + dx ; ordonnée + dy)
}

soit p: Point = Point(3 ; 4)

Le point #p a pour distance à l'origine #{p.norme()}. Translaté d'une unité dans chaque direction, il devient #{p.translaté(1 ; 1)}.

Le nom d'une classe commence par une majuscule : c'est ce qui le distingue d'un type du langage. Un attribut se lit avec un point, une méthode s'appelle de même. Dans le corps d'une méthode, les attributs sont visibles par leur nom, sans rien devant : la formule s'écrit comme au tableau.

Un attribut se modifie sans soit, puisque rien n'est déclaré :

soit q: Point = Point(1 ; 2)
q.abscisse = 6

Le point q vaut #q.

<page suivante h2algo>Premier pilier : l'encapsulation

Une classe peut garder pour elle ce qui ne regarde pas le dehors. Un seul mot le dit, et tout ce qui n'est pas marqué reste visible.

soit une classe Compte {
	titulaire: une chaîne de caractères
	privé solde: un réel

	privé soit taux(): un réel = 0,02
	soit intérêts(): un réel = solde * taux()
}

soit c: Compte = Compte("Léa" ; 250)

Le titulaire se lit du dehors : #{c.titulaire}. Les intérêts se calculent : #{c.intérêts()} — la méthode publique lit l'attribut privé et appelle la méthode privée, ce qui est tout l'objet de l'encapsulation.

Le solde ne se lit pas du dehors, et la méthode privée taux ne peut pas être appelée de l'extérieur : ces deux tentatives sont vérifiées dans les tests historiques.

<h2algo>Deuxième pilier : l'héritage

Une classe peut reprendre une autre et la prolonger. Elle en reçoit les attributs, les méthodes et les secrets.

soit une classe Animal {
	nom: une chaîne de caractères

	soit cri(): une chaîne de caractères = "..."
	soit carte(): une chaîne de caractères = nom
}

soit une classe Chien qui hérite de la classe Animal {
	race: une chaîne de caractères

	soit cri(): une chaîne de caractères = "ouaf"
}

soit une classe Chat qui hérite de la classe Animal {
	soit cri(): une chaîne de caractères = "miaou"
}

soit rex: Chien = Chien("Rex" ; "berger")

Rex reçoit de sa classe mère la méthode carte, qui donne #{rex.carte()}, et redéfinit cri, qui donne #{rex.cri()}. L'animal, lui, garde le sien :

soit loup: Animal = Animal("Loup")

#{loup.cri()}

<h2algo>Troisième pilier : le polymorphisme

Un chien tient la place d'un animal. C'est la valeur qui décide de la méthode appelée, non le type écrit :

soit fait(x: Animal): une chaîne de caractères = x.cri()

#{fait(rex)} — la fonction attend un animal, elle a reçu un chien, et c'est le cri du chien qui sort.

Rangés ensemble, chacun garde le sien :

soit z: une liste d'Animal = {Chien("Rex" ; "berger") ; Chat("Mia")}

pour a: un Animal dans z {
	[#{a.cri()}]
}

<h2algo>Quatrième pilier : l'abstraction

Une classe peut dire ce que ses filles doivent savoir faire, sans dire comment. Une méthode déclarée sans membre droit n'a pas de corps.

soit une classe abstraite Forme {
	nom: une chaîne de caractères

	soit aire(): un réel
	soit carte(): une chaîne de caractères = nom
}

soit une classe Carré qui hérite de la classe Forme {
	côté: un réel

	soit aire(): un réel = côté * côté
}

soit une classe Rectangle qui hérite de la classe Forme {
	largeur: un réel
	hauteur: un réel

	soit aire(): un réel = largeur * hauteur
}

soit mesure(f: Forme): un réel = f.aire()

Un carré de 3 a pour aire #{mesure(Carré("c" ; 3))} ; un rectangle 2 sur 5 a pour aire #{mesure(Rectangle("r" ; 2 ; 5))}. La fonction mesure ne sait rien de l'une ni de l'autre : elle sait seulement qu'une forme a une aire.

Une classe abstraite ne s'instancie pas : seules les classes concrètes Carré et Rectangle peuvent créer des objets. Le refus de l'instanciation directe reste testé séparément.

<page suivante h1algo>L'arbre binaire, écrit avec des objets

Les quatre piliers suffisent à écrire un arbre, sans avoir besoin d'une valeur nulle : l'arbre vide est une classe. La hiérarchie dit tout — un arbre est vide, ou c'est un nœud.

soit une classe abstraite Arbre {
	soit taille(): un entier
	soit hauteur(): un entier
}

soit une classe Vide qui hérite de la classe Arbre {
	soit taille(): un entier = 0
	soit hauteur(): un entier = 0
}

soit une classe Nœud qui hérite de la classe Arbre {
	valeur: un entier
	gauche: Arbre
	droit: Arbre

	soit taille(): un entier = 1 + gauche.taille() + droit.taille()
	soit hauteur(): un entier = 1 + max(gauche.hauteur() ; droit.hauteur())
}

soit t: Nœud = Nœud(1 ; Nœud(2 ; Vide() ; Vide()) ; Nœud(3 ; Vide() ; Vide()))

Cet arbre compte #{t.taille()} nœuds et sa hauteur vaut #{t.hauteur()}.

Un attribut peut donc contenir un objet : c'est ce qui permet à une structure de se contenir elle-même.

<h1algo>Les graphes

Un graphe se donne par sa liste d'adjacence : un dictionnaire dont chaque clé est un sommet et chaque valeur la liste de ses voisins.

soit g: un dictionnaire de chaînes de caractères et de listes de chaînes de caractères = {"A": {"B" ; "C"} ; "B": {"D"} ; "C": {"D"} ; "D": {}}

Le graphe compte #{longueur(g)} sommets ; les voisins de A sont #{g["A"]}.

Les deux parcours diffèrent par une seule chose : la file donne le parcours en largeur, la pile le parcours en profondeur.

soit largeur(g: un dictionnaire de chaînes de caractères et de listes de chaînes de caractères ; départ: une chaîne de caractères): une chaîne de caractères = {
	soit vus: une chaîne de caractères = ""
	soit f: une file de chaînes de caractères = {}
	f = enfiler(f ; départ)
	tant que est vide(f) vaut faux faire {
		soit s: une chaîne de caractères = tête(f)
		f = défiler(f)
		si vus contient(s) vaut faux {
			vus = vus + s
			pour v: une chaîne de caractères dans g[s] {
				f = enfiler(f ; v)
			}
		}
	}
	retourne vus
}

soit profondeur(g: un dictionnaire de chaînes de caractères et de listes de chaînes de caractères ; départ: une chaîne de caractères): une chaîne de caractères = {
	soit vus: une chaîne de caractères = ""
	soit p: une pile de chaînes de caractères = {}
	p = empiler(p ; départ)
	tant que est vide(p) vaut faux faire {
		soit s: une chaîne de caractères = sommet(p)
		p = dépiler(p)
		si vus contient(s) vaut faux {
			vus = vus + s
			pour v: une chaîne de caractères dans g[s] {
				p = empiler(p ; v)
			}
		}
	}
	retourne vus
}

Depuis A, en largeur : #{largeur(g ; "A")}. En profondeur : #{profondeur(g ; "A")}.

<h1algo>Écrire un résultat sur une ligne

soit premiers(n: un entier): une liste d'entiers = {
	soit p: une liste d'entiers = {}
	pour m: un entier naturel de 2 à n {
		soit d: un entier naturel = 0
		pour k: un entier naturel de 2 à m - 1 {
			si reste de m par k vaut 0 {
				d = d + 1
			}
		}
		si d vaut 0 {
			p = ajouter(p ; m)
		}
	}
	retourne p
}

Les nombres premiers jusqu'à 50 : #{joindre(premiers(50) ; ", ")}.

La primitive joindre évite l'accumulateur, qui laisse toujours un séparateur de trop à la fin.

Pour n points dont h forment l'enveloppe convexe, la triangulation de Delaunay compte exactement 2n − h − 2 triangles. Les sommets du diagramme de Voronoï sont les centres des cercles circonscrits de ses triangles.

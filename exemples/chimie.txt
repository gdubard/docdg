<h1vert>Cinétique des réactions complexes : intégration numérique

Dès que plusieurs réactions s'enchaînent, les lois de vitesse forment un système différentiel ; docdg l'intègre par une méthode de Runge-Kutta adaptative, avec une méthode implicite quand le système est raide.

<h2vert>Réactions successives A → B → C
Pour deux réactions d'ordre 1 de constantes k1 et k2, l'intermédiaire B passe par un maximum.
<Résoudre>numériquement le système différentiel, avec k1 = 1, k2 = 0,5, a(0) = 0,01, b(0) = 0 et c(0) = 0, sur [0 ; 10] {
	a' = -k1 a
	b' = k1 a - k2 b
	c' = k2 b
}
	<remarque>Le maximum de B est atteint en t = ln(k1/k2)/(k1 - k2) ≈ 1,39 s, ce que la courbe permet de vérifier.

<page suivante h2vert>Une cinétique raide : le problème de Robertson

<Résoudre>numériquement le système différentiel, avec a(0) = 1, b(0) = 0 et c(0) = 0, sur [0 ; 40], par la méthode de Radau, rtol = 1e-6, atol = 1e-10 {

	b' = 0,04a - 1e4 b c - 3e7 b^2
	c' = 3e7 b^2
}
	<remarque>L'espèce B reste à l'état de traces, de l'ordre de 10⁻⁵ : c'est l'intermédiaire réactionnel très réactif qui rend le système raide.

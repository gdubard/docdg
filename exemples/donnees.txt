<volume>Analyse de données — des relevés à la loi

Six stations de montagne, un an de relevés quotidiens. Ce document lit les fichiers, décrit les séries, choisit et regroupe par des requêtes, relie la température à l'altitude, puis conclut par une estimation et un test. Rien n'y est recopié à la main : chaque nombre vient des fichiers, et suit leurs corrections.

Les stations et leurs mesures sont fictives. Le script « outils/ecrire_donnees_exemple.py » les tire d'un modèle simple, toujours le même : une saison, un refroidissement régulier avec l'altitude, un aléa.

<h1>L'écart à la normale
La base range aussi les normales mensuelles de chaque station. Le SQL reste à disposition, pour le cours où il est l'objet d'étude : la requête s'adresse alors à la base, dont elle lit directement les tables. Une jointure sur la station et le mois compare l'année à ses normales ; un écart négatif se lit sous l'axe.
soit ecarts une table telle que ecarts = <Interroger>la base "DONNEES/meteo.duckdb" {
	SELECT normales.mois AS mois, ROUND(AVG((Minimale + Maximale) / 2) - temperature, 2) AS ecart
	FROM releves
	JOIN normales ON normales.station = releves.Station
		AND normales.mois = month(Jour)
	WHERE releves.Station = :station
	GROUP BY normales.mois, normales.temperature
	ORDER BY normales.mois
}
